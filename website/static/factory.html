Any gate obtained from this one by a change of output basis (a CNOT circuit on the outputs) and diagonal Clifford corrections (S, Z, CZ) prepares the same magic state, so this factory makes it too. Type a target gate on these outputs: if it is reachable, the circuit that gets there is constructed and checked on every basis state.

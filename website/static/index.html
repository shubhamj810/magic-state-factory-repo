How to read an entry

A factory is a binary matrix. Each column is a \pi/4 parity rotation, which consumes one noisy T state. Each row is a wire. The first k rows are outputs. The other r rows are checks, which are measured and postselected. The gate the factory applies to its outputs is read off the overlaps between rows.

n
Noisy T states consumed per run.
k
Output qubits.
d
Distance. Input errors of rate p leave an output error of order p^d. Exact distances are proved and witnessed. The others are proved lower bounds.
N,\ r
Wires in total, and the r = N - k checks.
T-count
The minimal T-count of the output gate, where it could be computed.
\gamma
\log(n/k)/\log d. Overhead per output qubit.
\gamma_T
\log(n/T)/\log d, with T the T-count. Overhead per unit of T-count.
\gamma_\rho
\log(n/V_{\mathrm{ex}})/\log d. Overhead per extractable T state. We rank by this one.

For a pure T^{\otimes k} gate the three exponents agree. Lower is better for all of them.

Two circuits with the same n, k and d share a row when a CNOT circuit and S, Z and CZ gates on the outputs turn one gate into the other. Such gates prepare the same magic state. For example, \mathrm{T}_0\cdot\mathrm{T}_1 and \mathrm{T}_0\cdot\mathrm{CS}_{01} are one class.

    Send a factory in any format, such as a paper, matrices, code or a notebook. Open a pull request with a folder in community_contributions/submissions, or attach it to an issue. We verify each submission like any other row and credit you on every class it adds.

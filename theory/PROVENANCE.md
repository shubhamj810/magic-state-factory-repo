# Result provenance

This file maps each claim this repository makes to the artifact that produces or
certifies it. It distinguishes complete classification from verified search
witnesses.

## Provenance rules

- **Classified:** the outer parent list and inner output enumeration are both
  complete. Absence inside the declared window is meaningful.
- **Certified search optimum:** one SAT instance completed `OPTIMAL` or `UNSAT`.
  The claim applies only to its exact `(k,N,target,d,level)` parameters.
- **Verified witness:** explicit columns reproduce the claimed gate and
  distance. No optimality or nonexistence statement follows.
- **Analytic:** columns are generated by a closed-form construction and then
  verified like any other witness.

## Parent-check claims

The filter chain `tau_D <= mu_d <= kappa_d`, targeted solver, compatible
subspace enumeration, and gate actions are implemented once in
[`factorylib/parent.py`](../factorylib/parent.py). They are exercised directly
through [`parent_first/cli.py`](../parent_first/cli.py) and over the complete
rank-7 outer list through [`rank7.py`](../classification/rank7_census/rank7.py).

The worked `[[15,1,3]]`, `[[28,2,3]]`, and `[[47,3,3]]` values are executable
regressions in [`parent_first/tests/`](../parent_first/tests/).

## Search catalogue

The sole source of retained examples is
[`symmetry_sat_search/examples/found_factories.json`](../symmetry_sat_search/examples/found_factories.json).
It contains 57 explicit circuits and a provenance string per row. Historical
solver stdout and one-off campaign wrappers are not required to reproduce or
verify these circuits.

Being precise about what that does and does not give you. Every row is
*verifiable* from its columns alone, by two independent verifiers, and that is
what the catalogue's claims rest on. Every row is also *re-searchable*: the
engine CLIs take any `(k, N, target, distance, level)`, and a row whose target is
an entangled multi-monomial gate -- the ones whose `target` field is a campaign
descriptor rather than a named gate -- is asked for with
`sat_search.py --target-monomials`, in the notation the catalogues print gates
in. What is *not* replayable is the historical campaign itself: the order in
which geometries were tried, and its total wall-clock, are gone with the
wrappers, and no claim here depends on them.

Provenance groups in that file cover:

- analytic level-2/3/4 simplex chains;
- early symmetry-reduced CP-SAT binary-matrix exports;
- fully symmetric, cyclic, subgroup-relaxed, and automorphism-seeded slot
  searches;
- ansatz-free SAT results;
- author-supplied census and relabel-search witnesses.

[`build_catalog.py`](../symmetry_sat_search/build_catalog.py) treats every row as
untrusted and re-derives shape, all check-touching parities, output gate,
distance, T-count, and reduced degree. It writes
[`factories.json`](../symmetry_sat_search/catalog/factories.json) and
[`FACTORY_CATALOG.md`](../symmetry_sat_search/catalog/FACTORY_CATALOG.md).

Two further checks use the generated data:

- [`verify_catalog.py`](../symmetry_sat_search/verify_catalog.py) re-derives
  every generated row's numbers from its columns, catching a stale or edited
  catalogue file. It shares `evaluator` and `factorylib.metrics` with the
  builder, so it is a re-derivation rather than a second implementation.
- [`symmetry_groups.py`](../symmetry_sat_search/symmetry_groups.py) computes
  each circuit's automorphism group, and
  [`rebuild_from_groups.py`](../symmetry_sat_search/rebuild_from_groups.py)
  reconstructs all 57 circuits from group generators and column-orbit
  representatives alone.

Search records are existence witnesses unless the associated solver status in
their provenance is an exact `OPTIMAL`/`UNSAT` certificate. They are never used
to justify the complete-window absence statements above.

## Gate metrics

All catalogues use the same implementation:

- [`factorylib/tcount.py`](../factorylib/tcount.py): exact minimal level-3
  T-count via the Amy–Mosca/Reed–Muller coset problem;
- [`factorylib/degree.py`](../factorylib/degree.py): CNOT-frame-reduced genuine
  phase-polynomial degree;
- [`factorylib/metrics.py`](../factorylib/metrics.py): parsing, caching, and
  catalogue-facing annotations.

This shared implementation removes the possibility that separate directory
copies silently report different metrics.

## Figures

[`theory/figures/landscape_all.py`](figures/landscape_all.py) reads all three
generated JSON catalogues and produces the cross-cutting figures. The figures are
a rendering of those catalogues and are not themselves computational
certificates: every number in them comes from a catalogue that was verified from
explicit columns.

The complete command sequence is in [`../REPRODUCING.md`](../REPRODUCING.md).

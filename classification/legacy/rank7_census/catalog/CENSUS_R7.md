## The window

This catalogue closes a window cut by the number of **check qubits**, not
by the T-count: every factory whose check code has effective rank `r ≤ 7`,
for any `n ≤ 44`. The sibling directory
[`../../exhaustive_n38/`](../../exhaustive_n38/) closes the complementary
window — *every* rank, but only `n ≤ 38`.

The outer enumeration is complete because the rank-≤7 triorthogonal check
supports are exactly the codewords of `RM(3,7)`, and Gillot–Langevin
classified those: 3,486 `AGL(7,2)` orbit representatives, of which 71 have
nonzero weight ≤ 44. Sweeping all 128 markings of each covers effective
ranks 4–7 in one pass.

## Headline

- Across the whole window the **maximum exact minimal T-count is T = 5**, and it is attained only at `n = 43`.
- **21 distinct `(n, k, S_k gate)` classes** realise it, every
  one with an explicit verified circuit. This is every T-count-5 class the
  census produced: the sweep's own representatives and the witnesses
  written out in [`../docs/HIGH_TCOUNT_FACTORY_WITNESSES.md`](../docs/HIGH_TCOUNT_FACTORY_WITNESSES.md)
  are both folded in here and deduplicated under the same `S_k` key as the
  rest of the repository, so no witness we found is left unaccounted for.

The two halves of that statement have different provenance. That
T = 5 **is reached** is certified by the explicit circuits below:
every one is re-derived from its columns by this builder and by the
tests. That it is **never exceeded** rests on a completed all-origin
census run whose output is too large to ship; it is recorded by
SHA-256, with its geometry count and mode, in
[`../../exhaustive_n38/results/n38_k56_certificate.json`](../../exhaustive_n38/results/n38_k56_certificate.json)
(`proof_partition.rank_le_7.completed_run_provenance`). What is local
and cheap is the outer enumeration: the `2^64` orbit-size identity and
the 9,088 marked geometries, both covered by the tests. See
[`../README.md`](../README.md), "What ships, and what the headline
rests on".

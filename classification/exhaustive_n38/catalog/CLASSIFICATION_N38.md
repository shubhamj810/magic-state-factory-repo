# Exhaustive distance-≥3 classification, `n ≤ 38`

Every distinct logical gate realisable by a reduced distance-≥3 factory
with at most 38 physical injections, together with an explicit verified
circuit for each. Generated by [`build_catalog.py`](../build_catalog.py)
from the runs in [`../results/`](../results/) — **do not edit by hand**.

Machine-readable companion: [`classification_n38.json`](classification_n38.json).

## What "exhaustive" means here

For each classified triorthogonal check-part support at physical length
`n ≤ 38` (the Kasami–Tokura / Nezami–Haah affine class representatives in
[`../nezami_haah_reps.py`](../nezami_haah_reps.py)), **every** way of
attaching output rows was enumerated in the quotient `V = R(C)/C`. No
target was requested and no node budget was consumed: the table answers
"which gates exist *at all* at this T-count and distance", not "can we
find gate X".

### The precise scope of the word "exhaustive"

The enumeration covers factories whose `k` output rows are linearly
independent **modulo the check span `C`**. Frames whose rows collapse
mod `C` — one output `a`, another `a + c` for a check-span element `c` —
are not enumerated.

**This costs no magic.** Such a frame is a real circuit, and its gate is
genuinely different (`0+1+01`, i.e. `T₀·T₁·CS₀₁`). But one output CNOT
turns the second row into `c` itself, which carries no monomial of any
degree — `|c|` is even, `|c ∧ a'|` is even for every `a'` in `R(C)`, and
`|c ∧ a' ∧ a''|` is even for every compatible pair. So after one Clifford
the extra output is an idle `|+⟩` spectator and what remains is exactly
the lower-width factory that *is* in this table. The arithmetic agrees:
`T₀·T₁·CS₀₁` has exact minimal T-count **1**, not 2, because
`x₀ + x₁ + 2x₀x₁ = (x₀ ⊕ x₁) + 4x₀x₁` — one T on the parity of the two
outputs, times a CZ.

So this catalogue is complete for magic **content** — which gates are
achievable at each `n`, the largest genuine output width, the largest
exact T-count. It is incomplete only for circuit **representations** in
which an output is Clifford-equivalent to an idle spectator. The engine
already discards frames with a manifestly idle output, so this is the
same policy one Clifford deeper rather than a different one.

If you are counting distinct circuits rather than distinct resources,
[`../classify_rowspace.py`](../classify_rowspace.py) enumerates in the
full row space and does reach them. A concrete example is the
`[[15,2,3]]` with gate `0+1+01` over the `[[15,1,3]]` check part: 6 rows
of rank 5, exact T-count 1. It is deliberately absent from the search
catalogue, which rejects a width whose output rows are dependent modulo
the check span — one CNOT leaves the second output idle, so the circuit is
the `[[15,1,3]]` on a spare wire. See
[`../../../symmetry_sat_search/examples/README.md`](../../../symmetry_sat_search/examples/README.md).

The one maximally symmetric parent — the 31 nonzero points of `F₂⁵`, whose
automorphism group is all of `GL(5,2)` — is settled separately by
[`../hard_parent_n31.py`](../hard_parent_n31.py), which collapses the
search along that group instead of enumerating through it.

## Deduplication: the key is S_k

Rows are deduplicated by `(n, k, gate up to a PERMUTATION of the output
qubits)`. Not up to `GL(k,2)`, which is strictly coarser and would merge
rows. Each row also carries its `GL(k,2)` class as an annotation, so a
`GL(k,2)` census can be recovered by grouping on that field without
re-running anything. [`../dedup.py`](../dedup.py) explains the choice and
its consequences in full; the short version is that a CNOT frame change on
the outputs produces a *different circuit* with a *different phase
polynomial*, and this is a construction catalogue.

**Row counts are upper bounds on class counts.** A raw gate string is a
representation, not an invariant. Maxima — largest `k`, largest `T`, which
gates occur at a given `n` — are unaffected.

## Notation

An output gate is a phase polynomial over F₂ monomials in the output qubits
`0..k-1`: degree 1 is a `T`, degree 2 a `CS`, degree 3 a `CCZ`. So
`0+1+01` = `T₀·T₁·CS₀₁`. `T` is the exact minimal T-count of the deposited
gate (Amy–Mosca / Reed–Muller minimum-weight coset over ℤ₈); `deg` is the
CNOT-frame-reduced phase-polynomial degree, minimised over output frames in
`GL(k,2)`. `N` = ambient circuit qubits = `k` outputs + checks.

### Headline findings

- Gate content: **22** T-only, **24** CS-level,
  **28** CCZ-level classes.
- **Pure `CCZ` (the monomial `012` alone) never occurs for `n ≤ 38`.**
  Inside this window CCZ content appears only inside fully-symmetric
  degree-≤3 combinations. This table *is* the witness for the `CCZ ≥ 39`
  distance-3 lower bound.
- Maximum output width in the window: **k = 5**.
- Highest exact minimal T-count: **T = 4**.

# Local search output

This directory is reserved for scratch outputs from `slot_search.py`,
`sat_search.py`, and `exact_d4.py`. Raw logs, timeouts, and campaign sweeps are
not publishable data and should not be committed.

When a result is worth retaining, copy its explicit circuit and provenance into
[`../examples/found_factories.json`](../examples/found_factories.json), then run
the catalogue verification pipeline described in [`../README.md`](../README.md).
